# Portfolio

Cyberpunk SvelteKit portfolio with a private Owner Interface for managing projects, skills, experience, GitHub-backed project data, and visitor analytics.

## Features

- SvelteKit public portfolio
- GitHub repo sync for public and private repositories
- Owner dashboard for managing content
- Turso/libSQL database backend
- Vercel deployment
- Privacy-friendly visitor analytics
- Server-Sent Events for live refresh
- Cyberpunk / CRT-inspired UI theme

## Tech Stack

- SvelteKit
- Svelte 5
- JavaScript
- Turso / libSQL
- Vercel
- GitHub API
- CSS / Tailwind v4
